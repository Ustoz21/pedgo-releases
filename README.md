# PedGo — Android APK yangilanishlari

Bu ommaviy repozitoriy faqat **PedGo Android ilovasining APK relizlarini** tarqatish uchun mo‘ljallangan.

- Android ilovaning asosiy manba kodi bu yerda saqlanmaydi.
- Yangi versiyalar [Releases](https://github.com/Ustoz21/pedgo-releases/releases) bo‘limida joylanadi.
- Har bir APK doimiy Android signing kaliti bilan imzolanadi.
- PedGo yangilanish tizimi rasmiy release tagi, GitHub SHA-256 digest va Android ilova imzosini tekshiradi.
- Foydalanuvchi tasdiqlamaguncha yangilanish o‘rnatilmaydi.

Birinchi release hali joylanmagan. Noma’lum manbalardagi APK fayllarga ishonmang.
